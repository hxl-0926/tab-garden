# 验证范围

交付日期：2026-10-19。

本记录区分纯函数测试、平台适配器测试、浏览器演示检查与真实扩展加载，避免把模拟环境的成功写成真实 Chrome 已验证。

- Node.js 22.14.0 / Windows：17 项核心、服务与预览测试。覆盖 URL 边界、并发保存、过期清理计划、快照存储失败、恢复失败、撤销、导入校验与预览入口资源加载。
- 浏览器演示：Chrome 155 中检查搜索、随机抽签、标记已读和重复页确认流程；使用独立的本地演示数据。
- 真实扩展：在 Playwright 1.64.1 / Chromium 156 的临时配置中加载 Manifest V3，3 项端到端测试通过。
- 端到端测试实际调用 Chrome tabs、tabGroups、windows 和 storage API：验证收藏跨刷新持久保存、已读/删除/撤销、JSON 导出再导入、文本注入防护、真实标签分组、快照先保存再清理、恢复到新窗口、390px 窄屏布局与键盘搜索。
- 测试网页为隔离环境中的合成页面，不验证真实网站登录、媒体播放或表单恢复。固定/音频保护与隐身过滤由核心测试覆盖。

扩展尚未安装到使用者的日常浏览器，也未提交 Chrome 应用商店审核。快照只恢复链接，无法恢复未提交表单或页面运行状态。

GitHub Actions 状态以对应仓库的工作流运行结果为准。
